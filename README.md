# Canadian Way Driver Training

- _Date Created_: 21 Jan 2025
- _Last Modification Date_: 30 August 2025
- A responsive web application designed to help new drivers in Halifax learn road rules and prepare for driving exams. This was a group project built by a team of 5 Dalhousie University students for Canadian Way Driver Training, a Halifax driving school. The site gives new drivers online study guides and lets them book in-car driving lessons.
- This project was developed in a private GitLab repository. This GitHub repository is a copy of the final code, published without commit history or branches because the original repository contains client and team information. ## Setup

1. Run `npm install` in the root directory to install all dependencies.
2. Run `npm run dev` in the root directory to start the development server.
3. Navigate to `http://localhost:3000` in your browser to view the website.
4. To see your changes, refresh the page in your browser. If you have problems, try restarting the development server.
5. To stop the development server, press `Ctrl + C` in the terminal where you ran `npm run dev`.
