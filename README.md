## Setup

1. Clone the repository from the [GitLab URL](https://git.cs.dal.ca/courses/csci-x691/canadian-way-driver) provided above.
    - Open a terminal window and navigate to the directory where you want to clone the repository.
    - Run `git clone https://git.cs.dal.ca/courses/csci-x691/canadian-way-driver.git` in the terminal window.
    - Navigate to the root directory of the repository.
    - Switch to your desired branch using `git checkout <branch-name>`.
2. Run `npm install` in the root directory to install all dependencies.
3. Run `npm run dev` in the root directory to start the development server.
4. Navigate to `http://localhost:3000` in your browser to view the website.
5. To see your changes, refresh the page in your browser. If you have problems, try restarting the development server. (**Step 6** then **Step 3**)
6. To stop the development server, press `Ctrl + C` in the terminal where you ran `npm run dev`.
